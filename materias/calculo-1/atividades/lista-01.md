# Lista 01 — Limites

1. Calcule lim(x→3) (2x + 1).
2. Calcule lim(x→2) (x² - 4)/(x - 2). (Dica: fatore o numerador antes de
   substituir — é uma indeterminação 0/0.)
3. Dada f(x) definida por partes como f(x) = x + 1 para x < 2 e
   f(x) = 3x - 3 para x ≥ 2, calcule os limites laterais em x = 2 e diga se
   o limite existe.
4. Calcule lim(x→0) (√(x + 4) - 2)/x. (Dica: racionalize o numerador.)
5. Verifique se os limites laterais de f(x) = |x| / x em x = 0 são iguais.
6. Calcule lim(x→∞) (3x² + 2x)/(x² - 1).
7. Calcule lim(x→∞) (2x + 1)/(x² + 3).
8. Calcule lim(x→-∞) (5x³ - x)/(2x³ + 4).
9. Esboce o comportamento de f(x) = 1/(x - 1) perto da assíntota vertical
   x = 1 e discuta os limites laterais nesse ponto.
